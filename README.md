# Resume Builder Web App

A simple web-based resume builder that generates a structured resume from user input.

## 🚀 Features
- Input form for user details
- Live resume generation
- Structured sections (Objective, Skills, Projects, Certifications)
- Clean and responsive UI

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
